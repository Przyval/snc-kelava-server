# Enterprise Dashboard Specification

## 1. Design & Stack
**Professional, modern, and trustworthy.**

*   **Framework:** React (Vite) + TypeScript
*   **Styling:** TailwindCSS + **Shadcn/UI** (Clean, professional component library)
*   **Charts:** **Tremor** or **Recharts** (Optimized for business analytics)
*   **Deployment:** Static SPA (runs anywhere, simply reads generated JSONs)

## 2. Views & Modules

### A. Executive Dashboard (CEO/Owner)
*   **Goal:** "Pulse of the Business" in 5 seconds.
*   **Key Metrics:**
    *   Operational Health Score (0-100)
    *   Coverage Ratio (Scheduled vs Completed)
    *   Global On-Time % (Trend line)
    *   Critical Alert Ticker (e.g., "3 sites missed today")

### B. Operations Control Room (Ops Manager)
*   **Goal:** "Find and Fix Problems."
*   **Features:**
    *   **Live Watchlist:** Top 10 technicians with NO_PHOTO / SUSPECT_TIME.
    *   **Segment Filter:** Drill down by MOBILE vs STATION.
    *   **Audit Table:** Full searchable table of all anomalies.
    *   **Action Tracker:** Status of P1/P2/P3 fixes.

### C. Technician Report Card (Personal/HR)
*   **Goal:** "Fair Feedback."
*   **Features:**
    *   Search by Technician Name.
    *   **"Rapor Belajar" Card:**
        *   Grade (A-F) with Color Coding.
        *   Productivity Score (vs Target).
        *   Discipline Badges (On-Time Streak, Photo Hero).
    *   **Salary Impact:** (Optional) "Estimated Bonus: Eligible/Not Eligible".

## 3. Data Architecture (The "Static Lake")

The dashboard does **not** connect to DB directly. It reads **JSON Artifacts** generated by the KPI Agent.

**Why?**
*   **Security:** Database credentials stay on the secure runner, not exposed to browser.
*   **Speed:** Instant load time (pre-computed).
*   **Reliability:** Only "Iron Gate Approved" data is shown.

**Required JSON Artifacts (to be added to pipeline):**
1.  `dashboard_stats.json` (Summary metrics)
2.  `leaderboard_full.json` (Complete technician list with scores)
3.  `watchlist.json` (Anomalies)
4.  `trends.json` (Daily aggregate history)
